# 大肥鱼控制台 v1.1.0 更新说明

发布日期：2026-11-08 ｜ 上一版：v1.0.0（2026-11-07）

## 这一版新增了什么

### 1. 首次启动先选语言
- 第一次打开会进入欢迎页，可在 **日本語 / English / 简体中文 / 繁體中文** 中四选一。
- 选中即刻生效：控制台、新手引导、设置和提示文字立刻换成该语言，并记住选择，下次不再询问。
- 设置 → 外观 里新增「语言」卡片，随时都能切换。

### 2. 自动扫描已有机器人
- 欢迎页会扫描本机已经登录的机器人实体：
  - SnowLuma 的 `config/onebot_<QQ>.json` 账号；
  - AstrBot 的平台列表（`data/cmd_config.json`）。
- 最多显示前三条，并给出总数；没有扫描到时会提示先登录再扫描。
- 扫描是**只读**的，结果只记录在控制台自己的 `settings.json`，不会修改 AstrBot、SnowLuma 或任何插件配置。
- 语言选项只影响控制台界面，不会改变机器人回复语言。

### 3. 键盘操作
- 欢迎页：`←` `→` 切换语言，`1`–`4` 直接选择，`Enter` / 空格继续。
- 新手引导：`←` / `Esc` 上一步，`→` / `Enter` / 空格下一步，最后一步直接完成。
- 设置页：`↑` `↓` 切换分类，`1`–`4` 直达，`Esc` 返回主界面。
- 插件页：`Esc` 返回。

### 4. 更顺滑的过场动画
- 页面切换改为 0.17 秒的缓出滑入，返回主界面时反向滑回，背景图保持不动。
- 切换语言、切换设置分类改为即时重绘，连按方向键也会即时响应。
- 连续快速切页不会叠加位移；切换语言时托盘图标重建加了 120ms 防抖。
- 拖动窗口边缘缩放时，界面按新尺寸实时重排，不再等松开鼠标才刷新。

### 5. 排版与文案
- 全界面约 220 条文案补齐四语言。
- 按钮宽度按译文自动加宽，日文长按钮不再重叠；日志长行超出宽度时自动省略。
- 「关于」页版本行与「构建」字样也会跟随语言。

## 怎么升级

- **覆盖安装（推荐）**：解压 `DafeiyuConsole-v1.1.0-win64.zip`，把里面的 `大肥鱼控制台.exe` 覆盖到旧目录即可；`app\`、`cache\`、`settings.json` 都保留，机器人登录态不受影响。
- **全新安装**：解压到英文路径（如 `D:\DafeiyuBot`），双击 `大肥鱼控制台.exe`，按欢迎页选择语言后继续新手引导。

系统要求不变：Windows 10/11 64 位；首次使用需联网下载组件。

## Dafeiyu Console v1.1.0 — Release Notes

Released 2026-11-08.

- **First-run language picker** — choose 日本語 / English / 简体中文 / 繁體中文 on first launch; the choice applies instantly and is remembered. A language card in Settings → Appearance lets you switch later.
- **Robot discovery** — the welcome page lists bot accounts already signed in to SnowLuma (`config/onebot_<QQ>.json`) and AstrBot platforms. Read-only: results are stored only in the console's `settings.json`.
- **Keyboard control** — arrows / Enter / Esc / 1–4 on the welcome, guide, settings and plugins pages.
- **Smoother transitions** — 0.17s eased slide between pages, instant redraws for language and tab changes, debounced tray rebuild; the layout now follows live while you drag the window edge.
- **Layout fixes** — translated button widths, no overlapping Japanese labels, log lines truncated with an ellipsis.

Upgrade by replacing `大肥鱼控制台.exe` in your existing folder; `app\`, `cache\` and `settings.json` are kept.
