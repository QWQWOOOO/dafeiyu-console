大肥鱼控制台 v1.1.0 —— 使用说明
====================================

一、这是什么
  把 AstrBot 的面板嵌进一个桌面小窗口：左边点按钮启停，右边直接操作机器人面板。
  不用装 Python、不用开命令行、不用每次开浏览器。

二、准备
  1. Windows 10 / 11 64 位。
  2. 解压到英文路径，比如 D:\DafeiyuBot（别放 C:\Program Files，会没有写权限）。
  3. 首次使用需要联网下载 AstrBot 和 SnowLuma（约 300–400MB，视网络而定）。
  4. 想挂机器人，需要一个 QQ 小号。

三、第一次打开
  双击「大肥鱼控制台.exe」，会先看到语言选择页：
  日本語 / English / 简体中文 / 繁體中文，选中即刻生效并记住。
  页面下方会列出已经登录的机器人账号（SnowLuma 与 AstrBot），只做记录，不会改动机器人文件。
  点「继续」后进入新手引导：

  第 1 步 检查组件
    看到「未安装」就点右边的「安装」。
    - AstrBot：会 git clone 源码并建虚拟环境、装依赖，最慢的一步。
    - SnowLuma：下载官方发布包并解压。
    - QQ：打开官方下载页，装完回来点「重新检测」。

  第 2 步 启动服务
    点「一键启动」，等状态变成「运行中」（AstrBot 首次启动 15–30 秒）。

  第 3 步 登录 QQ
    点「打开 SnowLuma 面板」→ 浏览器打开 http://127.0.0.1:5099
    账号 admin，初始密码在 app\SnowLuma\console.log 里搜 initial credentials。
    用机器人 QQ 扫码登录，看到「已连接」再继续。

  第 4 步 连接机器人
    1) 打开 AstrBot 面板 → 左侧「平台」→「新增平台」→ 选 aiocqhttp。
    2) ID 随便填（比如 qq），点「启用」。
    3) 「反向 WS 地址」填：ws://127.0.0.1:6199/ws
    4) 「访问令牌」填 SnowLuma 里那一串（面板 →「配置」→「客户端」→ 找到 ws 那行 → 令牌）。
       两边必须一致；本机连接也可以两边都留空，但要都空。
    5) 保存后平台列表显示「在线」，回 QQ @ 机器人试一句。

  完成后点「完成配置」，以后再打开就直接进主界面。

四、日常使用
  启动 / 全部停止          —— 一键启停三个组件
  热重启 AstrBot           —— 改了插件/人设/配置后用，约 15 秒，QQ 不用重新扫码
  重启协议端               —— 改了 SnowLuma 的 OneBot 配置后用
  打开面板                 —— 用系统浏览器打开 AstrBot 面板
  看日志 / 打开目录 / 复制状态 —— 排查问题用

  键盘也能操作：
    欢迎页        ← → 切换语言，1–4 直选，Enter / 空格继续
    新手引导      ← / Esc 上一步，→ / Enter / 空格下一步
    设置页        ↑ ↓ 切换分类，1–4 直达，Esc 返回主界面
    插件页        Esc 返回

五、常见问题
  1. 面板一片空白？
     确认 AstrBot 状态是「运行中」，端口 6185 没被占用；不行就点「热重启 AstrBot」。
  2. 下载很慢 / 失败？
     GitHub 直连经常超时，控制台会自动换 gh-proxy / ghproxy 镜像重试；也可以开代理后重启软件。
  3. SnowLuma 密码忘了？
     删掉 app\SnowLuma\config\webui.json，重启协议端会重新生成初始密码（看 console.log）。
  4. 换了显示器 / 觉得字太小？
     设置 → 外观 → 字体，字号四档可选。
  5. 想换主题？
     设置 → 外观 → 主题：浅色 / 深色 / 跟随系统。
  6. 想换界面语言？
     设置 → 外观 → 语言：日本語 / English / 简体中文 / 繁體中文，切换立即生效。

六、目录说明
  大肥鱼控制台.exe   主程序
  runtime\python312  内置 Python（给 AstrBot 建虚拟环境用，别删）
  app\AstrBot        机器人本体（含登录态、插件、人设、数据库）
  app\SnowLuma       QQ 协议端
  cache\             模型与下载缓存
  settings.json      控制台设置
  paths.json         组件路径（搬目录后改这里）

  整个文件夹可以整体拷到别的电脑，登录态和插件都在里面。
